## Что нужно для запуска
* Python 3.14 (по крайней мере, я на нём писал. Но скорее всего запустится и на более старых версиях)
* SQL Server Management Studio 22 года
* ODBC Driver 17/18 for SQL SERVER
* Развёрнутая база данных из приложенного файла .bacpac (лютая бд -> ars_hacaton.bacpac)

---

### Установка и запуск
* Развёртывание базы данных
* Откройте SQL Server Management Studio (SSMS)
* Импортируйте приложение уровня данных (файл .bacpac из репозитория).

### Настройка подключения к БД
* Откройте файл application/DB_CONNECTION.py и в строке подключения замените строки "SERVER=ИМЯ_ВАШЕГО_СЕРВЕРА;" и "DATABASE=ИМЯ_БАЗЫ_ДАННЫХ;"
* Так же, при необходимости поменяйте версию установленного ODBC-драйвера

### Установка зависимостей Python
* Перейдите в директорию application, создайте виртуальное окружение (вообще, в application уже оно есть)
* Установите библиотеки pyodbc и flask

### Запуск сервера
* Находясь в папке application, запустите главный файл приложения
* После запуска открыть http://127.0.0.1:5000

---

## К сведению
application/app.py - **роуты flask**
application/DB.py - **функции для работы с базой данных**
application/DB_CONNECTION.py - **настройки подключения к базе данных через pyodbc**
application/templates/ - **HTML-шаблоны страниц**
application/static/css.css - **CSS шняга**
